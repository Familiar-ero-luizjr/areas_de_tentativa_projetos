# Laboratórios de acesso V0.4
Abra index.html após extrair o ZIP. Cada HTML possui o mesmo motor original, sem alterações, e um registro completo de contratos para permitir navegação entre telas offline. As telas de autenticação foram reconstruídas em elementos indexados e regras CSS selecionadas da referência; não há HTML bruto nem scripts do primeiro arquivo. O login demonstrativo original foi substituído pelo contrato visual do acesso. A Home e seus destinos de demonstração foram preservados, com atualização das entradas relacionadas ao login.

O adaptador genérico do laboratório coleta campos de formulário declarados em dados.camposFormulario e valida campos nativos antes da navegação; não modifica o interpretador. Senhas e arquivos não são persistidos. Use dados fictícios. Splash avança por toque; recuperação e criação de conta são simuladas. Documentos legais integrais não constavam no HTML de acesso. Login cliente usa as condições originais de onboarding; jornada advogado pós-login não foi definida.

A aba Fluxo lista as transições efetivas e indica propostas. Não há backend. Validação estática de referências e sintaxe JS; não é teste visual em navegador.
