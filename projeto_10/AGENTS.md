# Projeto 10

## Escopo

O Projeto 10 reúne o motor de fluxo atual e um visualizador de HTMLs de legado.

## Regras locais

- Mantenha o motor atual em `fluxo/`.
- Mantenha cada HTML histórico em `legado/htmls/`.
- Ao incluir ou remover um HTML de legado, atualize `legado/catalogo.json`; o motor do legado gera as abas a partir dele.
- Preserve links relativos para funcionamento no servidor local e no GitHub Pages.
