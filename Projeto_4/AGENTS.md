# Instruções — Laboratório de Telas JSON V4

## Escopo

Este diretório é um projeto independente. Trabalhe apenas em `Projeto_4/`, exceto se a solicitação pedir explicitamente uma mudança no catálogo da raiz.

## Fonte e publicação

- `index.html` é a entrada pública no GitHub Pages e deve permanecer autocontida.
- `index.html` é a versão publicada atual do laboratório V4.
- Os arquivos `ADVOGADOJA_LABORATORIO_TELAS_JSON_V4*.html` e os demais visualizadores são artefatos independentes de referência.
- Ao aprovar uma nova versão para publicação, copie seu conteúdo para `index.html` e atualize este README.

## Regras

- Preserve o uso de dados fictícios, sem credenciais, dados pessoais reais ou serviços externos obrigatórios.
- Não altere contratos JSON ou o renderizador universal sem validar o comportamento do artefato final.
- Mantenha links e recursos relativos para abertura independente no GitHub Pages.
