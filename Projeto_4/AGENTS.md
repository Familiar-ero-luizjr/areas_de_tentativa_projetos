# Instruções — Laboratório de Telas JSON V3

## Escopo

Este diretório é um projeto independente. Trabalhe apenas em `Projeto_4/`, exceto se a solicitação pedir explicitamente uma mudança no catálogo da raiz.

## Fonte e publicação

- `index.html` é a entrada pública no GitHub Pages e deve permanecer autocontida.
- `ADVOGADOJA_LABORATORIO_TELAS_JSON_V3 (1).html` é a fonte do artefato publicado.
- Para evoluir a fonte modular, siga primeiro `laboratorio_telas_json_v3/AGENTS.md`.
- Depois de uma recompilação aprovada, sincronize o artefato final com `index.html`.

## Regras

- Preserve o uso de dados fictícios, sem credenciais, dados pessoais reais ou serviços externos obrigatórios.
- Não altere contratos JSON ou o renderizador universal sem validar os testes previstos na documentação local.
- Mantenha links e recursos relativos para abertura independente no GitHub Pages.
