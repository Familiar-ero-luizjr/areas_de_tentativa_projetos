Como usar

Laboratório offline: árvores de elementos JSON, estilos de referência e ações independentes.

  1. Simular: abra em Entrar; clique em Entrar para ir à Home Profissional.
  2. Editar: clique em qualquer elemento no celular para selecioná-lo.
  3. Modificar: ajuste cor, posição e ação. Clique em Aplicar ação.
  4. Experimentar: volte a Simular e teste o novo comportamento.
  5. JSON: altere estrutura, estilos, ações, interações, dados ou estados por bloco.
  6. Salvar: exporte o JSON. Para recuperá-lo, use Importar JSON.

Cada tela é definida por nós em estrutura.fragmentos[].arvore. Ajustes de aparência ficam em estilos.elementos, e eventos em interacoes com referências ao catálogo acoes.

Ao importar JSON, alterações de conteúdo e CSS serão renderizadas sem chamadas remotas. Dados importados não devem conter informações confidenciais.

Este JSON é gerado diretamente das telas atualmente carregadas, inclusive as opcionais e as modificações realizadas no Editor ou importadas. A exportação usa o mesmo conteúdo exibido, compatível com a importação de coleções pela aba Árvore JSON. O código do motor não faz parte do catálogo.
