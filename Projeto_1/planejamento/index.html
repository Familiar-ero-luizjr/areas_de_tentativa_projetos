Como salvar sem perder nada

  1. Abra a aba no laboratório pelo servidor local ou GitHub Pages.
  2. Edite registros e estados. O indicador mostrará alterações em memória.
  3. Exporte o CSV depois de editar registros ou o JSON depois de editar etapas.
  4. Substitua o arquivo correspondente na pasta planejamento/ do GitHub e faça commit.
  5. Recarregue a aba: ela lê os dois arquivos publicados novamente.

Ao importar, os registros são substituídos pelo arquivo importado. Exporte sua versão atual antes de importar outra.

Regras anti-esquecimento

Validação e limitações

O navegador não pode gravar diretamente em arquivos locais nem enviar commits ao GitHub sem uma integração autenticada. Os botões exportam arquivos para você substituir no repositório.

Para carregar arquivos automaticamente, a pasta precisa ser servida por HTTP/HTTPS. Se abrir em file://, use os botões de importação manual.

Não armazenar senhas, chaves privadas, documentos pessoais reais ou tokens nestes arquivos, especialmente num GitHub público.
