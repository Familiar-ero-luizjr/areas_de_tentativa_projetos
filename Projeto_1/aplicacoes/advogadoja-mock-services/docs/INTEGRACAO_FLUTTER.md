# Integração Flutter

Este projeto não precisa ser importado pelo Flutter para ser útil. Ele primeiro serve para validar contratos e estados.

Quando houver integração:
1. estabilize os contratos;
2. exponha endpoints locais apenas se necessário;
3. faça o Flutter depender das mesmas formas de request/response;
4. troque mock por Firebase/serviço real sem alterar a regra da tela.
