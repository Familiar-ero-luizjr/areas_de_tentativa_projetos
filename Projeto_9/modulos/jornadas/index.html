Galeria / Modelo de dados

Modelo de importação e exportação

Uma única estrutura para uma tela, várias telas ou toda a coleção. A coleção inicial é carregada de data/documento.json. Cada importação ou edição atualiza os filtros e o JSON exportável.

1. Escolha o conteúdo a exportar

Os componentes são obtidos das referências em tela.estrutura.html.composicao e tela.componentes.instanciasRefs. Somente o conteúdo correspondente segue no arquivo.

Escopo da exportação
Selecionar telas

2. Como o Motor importa

  1. Leia um documento.json canônico de uma tela (tela e componentes) ou um JSON com os quatro campos do modelo de coleção.
  2. Identifique cada tela por identidade.id. Se o ID já existir, a tela é atualizada; se não existir, é adicionada.
  3. Registre as definições pelo ID do componente, sem alterar seus objetos. Telas podem compartilhar a mesma definição.
  4. Monte a prévia usando estrutura. Jornada e subjornada devem informar id, numero e nome na classificação da própria tela; os filtros usam somente esses valores.
Fonte inicial: data/documento.json. O motor usa apenas as telas e componentes nele declarados.

Uma tela importada com a classificação antiga, contendo apenas referências, ficará sinalizada como classificação pendente até receber id, numero e nome. Componentes com definições conflitantes exigem revisão.

3. JSON real gerado para a seleção

A exportação tem apenas tipo, versao, telas e componentes; a classificação completa permanece dentro de cada tela. Sem catálogo de jornadas adicional.


 
A tela importada continua no padrão {"tela":{...},"componentes":{...}}. A exportação da galeria reúne esses mesmos dados no índice {"tipo","versao","telas","componentes"}, sem contratos paralelos ou cópias de catálogo.
