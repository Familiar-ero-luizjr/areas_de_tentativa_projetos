# Biblioteca padronizada — 01 e 02

192 pastas independentes. O `motor.js` é idêntico em todas. Cada tela tem `index.html`, `style.css`, `motor.js`, `documento.json` e `README.md`.

Para abrir: extraia a pasta e, dentro dela, execute `python -m http.server 8000`; acesse `http://localhost:8000/`. O navegador precisa de HTTP para carregar `documento.json`.

**Status:** estrutura e motor gerados; homologação visual e funcional por tela ainda pendente. As rotas do plano são candidatas, não fatos confirmados.
