# Organizador de Vida — catálogo funcional

Catálogo funcional em HTML para explorar e organizar a visão de um produto de organização de vida.

## Abrir

Abra `index.html` em um servidor estático. A partir da raiz deste repositório:

```powershell
py -m http.server 8000
```

Em seguida, acesse `http://localhost:8000/Projeto_2/`.

No GitHub Pages, o endereço será:

`https://familiar-ero-luizjr.github.io/areas_de_tentativa_projetos/Projeto_2/`

## Conteúdo

- `index.html`: entrada publicada do projeto.
- `catalogo_funcional_mestre_organizador_de_vida.html`: arquivo-fonte recebido do catálogo.
- O acervo legado local é ignorado pelo Git; a página publicada não depende dele.

## Escopo

Este projeto é independente. Para regras de alteração com IA, leia [`AGENTS.md`](./AGENTS.md).
