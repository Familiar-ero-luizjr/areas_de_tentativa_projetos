Como funciona

Este hub abre arquivos HTML completos, sem bibliotecas externas. O modelo de exemplo está disponível em cada módulo. Use Exportar projeto e Abrir projeto salvo para transferir alterações com segurança entre módulos, especialmente se abrir os HTMLs diretamente do disco. O Catálogo tem motor autocontido e permite importar/exportar JSON; seus dados não dependem de outro módulo.
