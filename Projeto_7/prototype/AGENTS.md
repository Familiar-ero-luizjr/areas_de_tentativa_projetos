# AGENTS.md — Projeto 6

## Escopo

Este diretório concentra os protótipos independentes do Advogado Já e uma página inicial para abri-los. As demais pastas `Projeto_*` do repositório são independentes.

## Regras de manutenção

1. Preserve os arquivos HTML de origem enquanto a alteração não solicitar explicitamente sua evolução.
2. Mantenha o `index.html` com links relativos para os protótipos disponíveis.
3. Atualize este `README.md` e o índice do Projeto 6 quando adicionar, mover ou remover um laboratório.
4. Não duplique funcionalidades de um laboratório dentro de outro, a menos que isso tenha sido expressamente solicitado.
5. Dados, eventos, autenticação, armazenamento e estados das demonstrações são apenas simulados; não usar credenciais nem dados reais.
6. Verifique a abertura em desktop e celular, os links e o funcionamento offline antes de publicar.
7. Alterações fora de `Projeto_6/` devem restringir-se ao catálogo geral (index.html e README.md da raiz), quando solicitadas.
