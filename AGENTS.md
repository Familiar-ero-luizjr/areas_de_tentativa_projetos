# Instruções do catálogo

## Escopo

Esta raiz é apenas o catálogo e o ponto de publicação no GitHub Pages. Ela contém links para projetos independentes em `Projeto_1/`, `Projeto_2/` e `Projeto_3/`.

## Antes de editar

1. Identifique o projeto solicitado.
2. Leia o `AGENTS.md` mais próximo dentro daquele projeto.
3. Faça alterações exclusivamente naquele diretório, a menos que a solicitação envolva o catálogo ou a publicação comum.

## Regras

- Não misture requisitos, código ou documentação entre projetos.
- Mantenha um `index.html`, `README.md` e `AGENTS.md` na raiz de cada projeto.
- Use links relativos para compatibilidade com GitHub Pages.
- Não publique segredos, credenciais, tokens ou dados pessoais reais.
- Ao criar um novo projeto, atualize este `README.md` e `index.html` com um link para ele.

## Delegação entre agentes

O agente responsável pelo projeto pode delegar apenas tarefas específicas. Quem delega conserva a responsabilidade pelo escopo, integra o resultado e garante que a alteração respeita este contrato e o contrato local do projeto.
