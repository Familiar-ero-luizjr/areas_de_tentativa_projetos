# AGENTS — Protótipo com dois submódulos

- Este `index.html` é seletor. Não adicionar aqui motor de tela, nem unir as duas experiências em um único `app.js`.
- Manter `modular-v2/` e `cliente-v3/` com a **mesma estrutura padrão de arquivos**, mas motores e auxiliares inteiramente locais e independentes.
- Ambos consomem somente o Catálogo ativo; nenhuma cópia de telas canônicas, dados históricos ou Flutter.
- As funcionalidades de cada submódulo estão em seu próprio README e manifesto.
- O menu geral do Workspace deve aparecer em cada página; o submenu do Protótipo alterna os laboratórios.
- Ao modificar campos canônicos, validar ambos os leitores e motores.
- `app.js` e `motor.js` nesta pasta só definem a entrada e metadados dos dois laboratórios.
- Nunca inventar destino de navegação, não usar sequências editoriais como Flow.
