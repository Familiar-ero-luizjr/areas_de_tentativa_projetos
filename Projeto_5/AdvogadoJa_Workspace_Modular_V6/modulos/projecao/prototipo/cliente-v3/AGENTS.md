# AGENTS — Cliente Interativo V3

- Não alterar outros módulos ou o irmão por efeitos indiretos.
- É um laboratório HTML/CSS sem Flutter; usar apenas o catálogo ativo.
- Preservar `index.html`, `style.css`, `app.js`, `motor.js`, `montagem.js`, `catalogo.js`, `regras.js`, `resolvedor.js`, `ui.js`, `README.md`, `AGENTS.md` e `manifesto.modulo.json`.
- Componentes são resolvidos pelo ID no catálogo; não copiar telas ou contratos para esta pasta.
- Ações reais do fluxo vêm de `acoes`; sequências de demonstração não alteram navegação.
- Mocks declarados em `mocks.cenarios` servem apenas aos cenários simulados.
- Validar tela, estados, subabas, menus, volta, exportação e funcionamento mobile.

- Exibir Sequências e Relações como ferramentas do Cliente V3, sem transformar notas de percurso em arestas canônicas.
- Preservar dados digitados apenas na memória de sessão; nunca no JSON canônico. Não incluir credenciais em logs ou exportações.
- Considerar dados temporários no cálculo do contexto/variantes; não usar mocks para criar tabelas ou operações reais.
