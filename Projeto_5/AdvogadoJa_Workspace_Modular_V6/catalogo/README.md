# Catálogo ativo

O `indice.json` contém somente cinco telas e três componentes do Laboratório JSON V2. Os módulos leem somente os caminhos declarados nele.

Nenhum JSON de tela deve conter `flow` ou `flow.editor`. As edições podem ser feitas pelo módulo Catálogo com `python iniciar.py`, que salva nos arquivos físicos. Módulos geram índices e projeções temporários sem criar mestres paralelos.
