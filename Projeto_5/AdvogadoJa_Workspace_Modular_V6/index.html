Como utilizar

Execute python iniciar.py nesta pasta e abra http://localhost:8765. Os módulos carregam os JSONs individualmente pelo índice ativo. Alterações salvas pelo servidor atualizam os arquivos físicos; com Live Server, as alterações ficam em rascunho no navegador e devem ser exportadas.
