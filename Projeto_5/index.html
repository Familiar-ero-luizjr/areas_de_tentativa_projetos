Uso

No GitHub Pages, use o Workspace em modo leitura/exportação. Para gravar JSONs fisicamente, execute python iniciar.py na pasta AdvogadoJa_Workspace_Modular_V6 e abra http://localhost:8765.

Catálogo ativo: cinco telas e três componentes. Acervo pendente: 106 telas e 142 componentes antigos, preservados fora da execução dos motores.
